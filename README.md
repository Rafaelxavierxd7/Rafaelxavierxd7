### 02 &nbsp; / &nbsp; Projetos que orientam minha evolução

#### Projeto Evolução · Treino, alimentação e acompanhamento

Aplicação pessoal para organizar treinos, registrar alimentação e acompanhar a evolução ao longo do tempo. Reúne sessões de treino, histórico, gráficos, fotos privadas e configurações de metas.

**Tecnologias:** PHP · Laravel · MySQL · Blade · JavaScript · Alpine.js · Tailwind CSS · Chart.js.

<details>
  <summary><strong>Explorar funcionalidades e temas de aprendizado ↗</strong></summary>
  <br />

- **Fluxos com estado:** início, registro de séries, retomada e conclusão de uma sessão de treino.
- **Regras de negócio:** cálculos de alimentação, acompanhamento de medidas e preservação de dados históricos.
- **Organização do back-end:** rotas, controllers, validações, services, models e policies.
- **Persistência:** relacionamentos, migrations e transações para manter os registros consistentes.
- **Interface:** formulários, gráficos, temas claro/escuro e adaptação ao celular.
- **Qualidade:** o projeto contém testes automatizados de autenticação, autorização, cálculos e fluxos de uso com PHPUnit.

**Meu foco de evolução:** compreender como uma ação na interface é validada, processada, salva e apresentada novamente ao usuário.

</details>

[Explorar o repositório do Projeto Evolução ↗](https://github.com/Rafaelxavierxd7/individual-training-plan)

<br />

#### LinkBio · Página de links com painel e métricas

Aplicação com cadastro, login, perfis públicos e gerenciamento de links. O painel reúne contadores e registros de cliques, incluindo informações de dispositivo, navegador e origem.

**Tecnologias:** TypeScript · React · Next.js · Tailwind CSS · Supabase · PostgreSQL.

<details>
  <summary><strong>Explorar funcionalidades e temas de aprendizado ↗</strong></summary>
  <br />

- **Front-end:** componentes React, formulários, estado de interface e feedback de carregamento e erro.
- **Rotas:** páginas dinâmicas por perfil e uma rota de servidor para registrar cliques e redirecionar visitantes.
- **Autenticação:** integração com Supabase Auth e controle de acesso ao painel.
- **Dados:** relações entre perfis, links e cliques, com políticas de acesso por usuário no banco.
- **Integrações:** identificação de dispositivo e navegador e consulta de localização aproximada por IP.

**Meu foco de evolução:** entender a comunicação entre componentes, autenticação e banco de dados em uma aplicação com múltiplos usuários.

</details>

[Explorar o repositório do LinkBio ↗](https://github.com/Rafaelxavierxd7/Linkbio)

### 04 &nbsp; / &nbsp; O próximo nível de aprendizado

Meu foco está em conectar os fundamentos a problemas de uma aplicação: entender o que acontece quando um formulário é enviado, como os dados são protegidos e como uma mudança pode afetar o restante do sistema.

| Frente de evolução | Objetivo de prática |
| :--- | :--- |

| **Do código à confiança** | Reproduzir erros e criar testes para comportamentos importantes |
